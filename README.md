# منصّة المجلس

نموذج أولي تفاعلي لمنصّة المجلس الإشرافي المشترك للشركات الأربع. البيانات تجريبية وتُحفظ في متصفح كل مستخدم.

## الأقسام

- **الدورة الشهرية** — إرسال التقارير الشهرية ومراجعتها واعتمادها، محاضر الاجتماعات وتأكيدها، التصويت بالتمرير مع الإفصاح عن تعارض المصالح، طلبات الاعتماد بحسب مستوى الصلاحية، وحزمة الاجتماع القابلة للطباعة
- **المالية والموازنة** — الفعلي مقابل الموازنة وتوقع السيولة لثلاثة أشهر
- **الخدمات المشتركة، الموارد البشرية، إعداد المؤشرات، تقييم أداء المجلس**، والملخص الأسبوعي للواتساب
- **لوحة المجلس** — المؤشرات الموحّدة، المواعيد القادمة، العملاء والمستحقات، آخر النشاطات
- **ملفات الشركات** — المالية والمؤشرات والتقرير الشهري، مع عملاء الشركة ومستنداتها ومخاطرها ومهامها
- **العملاء** — المراحل والقيمة وأعمار المستحقات وسجل التواصل (أسماء عملاء المعرفة القانونية سرّية)
- **المستندات** — رفع الملفات ومعاينتها، مجلدات ونسخ وربط بالقرارات والعملاء
- **المهام والمتابعة الأسبوعية** — لوحة سحب وإفلات
- **التقويم** — الاجتماعات ومواعيد التقارير واستحقاق القرارات وتجديد العقود
- **سجل القرارات، الاجتماعات والنصاب، سجل المخاطر، الصلاحيات، خطة ٩٠ يومًا، الأعضاء**
- **سجل النشاط، الإعدادات** — العمل بصفة أي عضو، نسخ احتياطي واستعادة
- بحث شامل (Ctrl+K) وتنبيهات

صُمّم وطُوّر بواسطة **روّاد**.
